# Lesson 3 Prompts: Prepare for a Safe Feature Change

These three prompts are short enough to type during the lesson. The file is provided as an optional copyable reference.

## Prompt 1: Create the Readiness Plan

```text
Using BabyTrack and the delete-feed-entry feature brief, create a source-backed feature-readiness plan. Identify change points, risks, testing needs, and open questions with file citations. Do not implement the feature. Return the complete Markdown for `feature-readiness-plan.md`.
```

Save the response as `feature-readiness-plan.md`.

## Prompt 2: Review It Independently

Open a fresh AI conversation or another AI tool and attach BabyTrack, the feature brief, and `feature-readiness-plan.md`.

```text
Review the attached plan against BabyTrack and the feature brief. Flag unsupported claims, missed change points, unnecessary scope, risks, and open questions. Cite the source.
```

Verify the review and state which findings you accept, reject, revise, or want left unresolved.

## Prompt 3: Finalize the Plan

```text
Revise `feature-readiness-plan.md` using only the review findings I accepted. Preserve unresolved questions and rejected scope. Return the complete final Markdown without implementation code.
```
