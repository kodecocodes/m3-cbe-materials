# Lesson 2 Prompts: Create and Review a Modernization Plan

These three prompts are short enough to type during the lesson. The file is provided as an optional copyable reference.

## Prompt 1: Compare the Options

```text
Analyze BabyTrack's Objective-C, Swift, UIKit, and SwiftUI boundaries. Compare practical incremental modernization options, how old and new code can coexist, and the main risks and validation needs. Cite files and do not generate converted code.
```

Inspect the important citations and correct unsupported claims.

## Prompt 2: Build and Challenge the Sequence

```text
Turn the verified options into a small phased plan. Challenge unnecessary rewrites, unsafe ordering, and unsupported assumptions. For each phase, include its goal, scope, dependencies, interoperability, risks, and validation.
```

Accept, reject, revise, or defer the recommendations before continuing.

## Prompt 3: Create the Modernization Plan

```text
Create the complete Markdown for `modernization-plan.md` using the verified evidence and my decisions. Include the current state, migration approaches, phases, code to retain, risks, rejected or deferred ideas, open questions, and validation. Do not generate implementation code, and return only the Markdown file.
```
